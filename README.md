# 🚀 Cyberpunk Bio Links - LXStar Core System

Trang Web Bio Link cá nhân phong cách **Cyberpunk / Neon Glass UI** kết hợp trình phát nhạc Lofi, hiệu ứng tương tác Canvas và giao diện tối ưu cho Game thủ / Developer.

![Preview](assets/Avatar.png)

---

## ✨ Tính Năng Nổi Bật

- **🎨 Thiết kế Cyberpunk Glassmorphic:** Giao diện tối hiện đại, hiệu ứng viền phát sáng (Neon Glow) và chuyển động mượt mà.
- **🌌 Interactive Background Canvas:** Hiệu ứng hạt & các đường quét (Scanlines) phong cách Hacker/Cyber.
- **🎵 Floating Audio Player:** Trình phát nhạc nền Chill Lofi tích hợp Visualizer chuyển động.
- **⚡ Màn hình Intro Cinematic:** Hiệu ứng gõ chữ Terminal Matrix & đếm ngược khi truy cập.
- **🎛️ Bento Grid Layout:** Sắp xếp danh sách liên kết khoa học, bắt mắt, tương tác Tilt 3D.
- **💬 Pop-up Modal Discord:** Tích hợp cửa sổ Discord SERVER chuyên nghiệp hỗ trợ copy link nhanh.
- **📱 Responsive 100%:** Hiển thị mượt mà trên cả Điện thoại, Tablet và Máy tính.
